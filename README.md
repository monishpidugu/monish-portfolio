# Monish Abhinav – Portfolio Website

A dark, modern portfolio website built with React 18 + Vite.

## How to Run

Make sure you have **Node.js 18+** installed, then:

```bash
# 1. Open this folder in terminal
cd C:\mine\portfolio

# 2. Install dependencies (only needed once)
npm install

# 3. Start the dev server
npm run dev
```

Then open **http://localhost:5173** in your browser.

## Build for Production

```bash
npm run build
```

Output goes to the `dist/` folder — ready to deploy on GitHub Pages, Netlify, or Vercel.

## Sections

- **Hero** – Name, title, stats, quick links
- **About** – Bio, contact details, AI tools used
- **Skills** – Animated skill bars + tech badges
- **Experience** – Work timeline at Aptean
- **Projects** – Professional & personal project cards
